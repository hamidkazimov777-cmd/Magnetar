## Правила работы (не нарушать)
- Мелкими безопасными шагами, **одна задача за раз**. Задача трогает >5 файлов —
  сначала объясни и дождись подтверждения.
- После изменений: `npx tsc --noEmit` → `npm run build` → (если Rust)
  `cargo check --manifest-path src-tauri/Cargo.toml` + `cargo test` → коммит кода,
  затем отдельный коммит доков. Co-Authored-By: Claude Opus 4.8.
- Новый ключ i18n — сразу **ru + en + es** (`src/lib/i18n.ts`); проверка полноты
  python-скриптом (раздел 8 `NEXT_TASK_FILES.md`), должно быть `MISSING/DIFF []`.
- Новый баг — **сначала тест, потом фикс** (где применимо).
- В конце захода: допиши запись в конец `HANDOFF.md`, обнови `NEXT_TASK_FILES.md`.

## Сборка и показ Hamid'у (важный цикл)
Приложение стоит **в `/Applications`**, Hamid запускает **с дока** (не из
терминала). После правок фронта/Rust пересобирай и переустанавливай:
```bash
cd /Users/hamidkazimov/Magnetar
pkill -9 -f -i magnetar 2>/dev/null
npm run tauri build
APP=src-tauri/target/release/bundle/macos/Magnetar.app
rm -rf /Applications/Magnetar.app && cp -R "$APP" /Applications/
xattr -dr com.apple.quarantine /Applications/Magnetar.app 2>/dev/null
open -a /Applications/Magnetar.app
```
Чисто фронт можно смотреть и в браузер-превью (`preview_start name magnetar-web`),
но там нет Tauri-бэкенда (invoke падает — это норма для веба).

## Полезные факты / грабли
- **Hamid на Mac с трекпадом**: нет правого клика — **два пальца = контекстное
  меню**; F-клавиши через Fn. Инструкции давай под трекпад.
- Для логов Rust: запускай **внутренний бинарник бандла**
  (`…/Magnetar.app/Contents/MacOS/magnetar >/tmp/log 2>&1 &`) — голый
  `target/release/magnetar` даёт белый экран (вебвью без бандла не грузится).
- **fal.ai**: один ключ → много моделей. Nano Banana = вкладка «Изображения»
  (`fal-ai/nano-banana`), видео (Seedance/Veo/Kling) = вкладка «Видео» (async,
  1–3 мин). id видео-моделей fal иногда меняются — если ошибка, поправь строку в
  `GEN_PROVIDERS` (`src/lib/generation.ts`). GPT для фото = отдельное OpenAI-
  подключение (`gpt-image-1`).
- **Монохром**: `--color-ai` больше не цвет, а сильнейший передний план. Фиолетовый
  не возвращать.
- Студия: `src/components/StudioView.tsx`; вход — `centerView: "studio"` при
  `activeTrack === "generation"`; переключатель режимов — вверху `ActivityBar.tsx`.
