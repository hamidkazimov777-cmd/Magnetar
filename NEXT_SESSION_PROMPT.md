## Правила работы (не нарушать)

- Мелкими безопасными шагами, одна задача за раз.
- После каждого изменения: `npx tsc --noEmit` → `npm run build` →
  `cd src-tauri && cargo check` → `cargo test` → `npm run tauri build` →
  `git commit` (код), затем отдельный коммит доков.
- Новый ключ i18n — сразу **ru + en + es** (`src/lib/i18n.ts`); проверка полноты
  скриптом из раздела 8 `NEXT_TASK_FILES.md`.
- Новый баг — сначала тест, потом фикс.
- Задача трогает > 5 файлов — сначала объясни почему.
- В конце каждого захода: допиши запись в конец `HANDOFF.md` и обнови
  `NEXT_TASK_FILES.md` (дата + «готово, <hash>» + следующая задача). В
  `HANDOFF.md` только **добавляй**.
