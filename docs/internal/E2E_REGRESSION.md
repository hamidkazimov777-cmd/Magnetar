# E2E-регрессия Magnetar (ручной сценарий)

> Один стандартный сценарий, который прогоняется **после любых изменений**.
> Каждый шаг — с ожидаемым результатом: что именно считать успехом (PASS).
> Любой FAIL — регрессия, чинится до продолжения.

## Подготовка

1. `npm run smoke` — авто-проверки (типы, build, `cargo test`) и генерация фикстуры. Все 4 — PASS.
2. `npm run tauri build` — собирает `Magnetar.app`.
3. Открыть `src-tauri/target/release/bundle/macos/Magnetar.app`.
4. Фикстура уже лежит в видимой папке `~/Documents/Magnetar/_fixture`.

Открытие фикстуры: ⌘K → «Открыть папку» → **Documents → Magnetar → `_fixture`**
(это обычная видимая папка, скрытые файлы включать не нужно).
