# Стартовый промт для следующего ИИ

> Скопируй всё, что ниже линии, и вставь новому ассистенту первым сообщением.
>
> Здесь намеренно нет ни правил, ни карты файлов, ни истории: всё это живёт в
> `NEXT_TASK_FILES.md` и `HANDOFF.md`. Копия правил в двух местах разъезжается —
> и ассистент выполняет ту, что устарела.

---

Ты продолжаешь работу над **Magnetar** — AI IDE для macOS с постоянной памятью
проекта. Репозиторий: `/Users/hamidkazimov/Magnetar`
(`git@github.com:hamidkazimov777-cmd/Magnetar.git`, SSH-ключ авторизован).
Стек: Tauri v2 + Rust + React + TypeScript + Tailwind v4 + SQLite, BYOK.
Владелец — Hamid, пиши ему **по-русски**.

**Прочитай в этом порядке, до любых изменений:**

1. `NEXT_TASK_FILES.md` — текущее состояние, карта файлов и жёсткие правила.
   Правила не нарушать: каждое появилось после реального бага, причина записана
   рядом с правилом.
2. `OVERVIEW.md` — полный разбор приложения: философия, память, агент,
   провайдеры, данные. Отвечает на «почему так, а не иначе».
3. Последние записи `HANDOFF.md` — журнал разработки. Читать с конца.
4. `git log --oneline -5` и `git status`.

**Как работать:**

- Перед изменением архитектуры или стека — спроси.
- Каждое изменение проверяется: `npx tsc --noEmit`, `npm run build`,
  `cd src-tauri && cargo check`. Сборка приложения: `npm run tauri build`,
  затем `bash scripts/sign-app.sh`.
- Новый ключ i18n — сразу в ru + en + es (`src/lib/i18n.ts`), проверка полноты —
  скриптом из раздела 8 `NEXT_TASK_FILES.md`.
- Новый баг сначала воспроизводи тестом, потом чини. Примеры такого подхода уже
  есть: `tools.rs` (фоновый процесс не вешает прогон), `utf8.rs` (разрыв
  кириллицы на границе чанка), `workspace.rs` (round-trip памяти в SQLite).
- Говори прямо, если считаешь предложенное решение неверным. Владелец просил
  жёсткий разбор, а не поддакивание.
- Закончил заход — допиши запись в конец `HANDOFF.md` (что сделано, что сломано,
  что дальше, какие грабли) и обнови `NEXT_TASK_FILES.md`. Работа без
  обновлённых документов считается незавершённой. В `HANDOFF.md` только
  **добавляй**, ничего не удаляй.

**Чего не делать:**

- Не убивать приложение `kill -9` — вебвью не дописывает состояние.
- Не запускать `scripts/setup-signing.sh` — это изменение настроек безопасности,
  его выполняет владелец сам.
- Не строить скрытую автоматизацию подписочных ИИ через браузер — это обход
  условий использования, решение принято осознанно.

Начни с чтения `NEXT_TASK_FILES.md` и скажи, с чего продолжаешь.
