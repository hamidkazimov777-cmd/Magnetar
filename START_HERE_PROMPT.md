Ты продолжаешь работу над проектом **Magnetar** — десктоп-приложение macOS,
локальный ИИ-агент (уровня Claude Code): чат + написание кода + доступ к машине
(файлы, редактирование, команды), работающий с ЛЮБЫМ ИИ по API-ключу (BYOK).
Проект в `/Users/hamidkazimov/Magnetar`.

**ПЕРВЫМ ДЕЛОМ, до любых изменений:**
1. Прочитай `HANDOFF.md` целиком (журнал передачи — там что уже сделано, что не
   доделано, критичные детали GigaChat и следующий шаг). Читай ВСЕ записи, последняя
   — самая актуальная.
2. Прочитай `README.md` (стек, архитектура, чек-лист фаз).
3. Бегло просмотри структуру `src-tauri/src/` и `src/` чтобы освежить код.

**Стек фиксирован — без моего явного согласия не менять:** Tauri v2 (Rust) +
React + TS + Tailwind v4; секреты только в macOS Keychain (`security-framework`),
никогда в plaintext; SQLite (`rusqlite`) для провайдер-нейтрального канона.

**План по фазам:** 1) Каркас ✅ сделан — 2) SQLite + канон — 3) GigaChat-адаптер
— 4) агентские инструменты (read/write/edit/list_dir/grep/run_bash + подтверждения
разрушающих) — 5) handoff-заметки + экономия токенов (rolling-summary, prompt
caching, фильтрация вывода ~90%, retrieval, роутинг моделей).

**Жёсткие правила:**
- Секреты (API-ключи, GigaChat-креды) НЕ писать в файлы и НЕ коммитить — только в
  Keychain. Если для задачи нужны GigaChat-креды — попроси меня прислать заново.
- GigaChat — детали уже проверены в бою, не изобретай заново (см. HANDOFF.md:
  OAuth порт 9443, кэш токена ~30 мин, RqUID/User-Agent, Russian Trusted Root CA,
  mutex на 1 одновременный запрос, парсинг ```json от первого `{` до последнего `}`).
- Приложение локальное, наружу ходит только к настроенным мной API. Ничего «домой».
- Работай автономно, решения по мелочам принимай сам качественно; спрашивай только
  когда это реально влияет на архитектуру или требует моих секретов.

**Порядок работы:** возьми «Следующий шаг» из последней записи HANDOFF.md (если я
не сказал иначе), сделай его, проверь сборку (`cargo check`, `tsc --noEmit`,
`npm run build`, при возможности `npm run tauri dev`).

**Когда я тебя остановлю или ты закончишь сессию — ОБЯЗАТЕЛЬНО допиши новую запись
в конец `HANDOFF.md`** («Запись N — дата — модель — тема»: что сделал, что
сломано/не доделано, следующий шаг, как продолжить). Это нужно, чтобы передать
работу обратно другому ИИ без потери контекста. Старые записи не удаляй.

Запуск: `npm run tauri dev` из корня проекта (если cargo не в PATH — сначала
`source $HOME/.cargo/env`).

Начни с чтения HANDOFF.md и скажи, с какой фазы/задачи продолжаешь.
