# Стартовый промт для следующего ИИ

> Скопируй всё, что ниже линии, и вставь новому ассистенту как первое сообщение.

---

Ты продолжаешь работу над проектом **Magnetar** — десктоп-приложение macOS,
локальный ИИ-агент (уровня Claude Code): чат + написание кода + доступ к машине
(файлы, редактирование, команды), работающий с ЛЮБЫМ ИИ по API-ключу (BYOK).
Проект в `/Users/hamidkazimov/Magnetar`, репозиторий:
`git@github.com:hamidkazimov777-cmd/Magnetar.git` (SSH-ключ уже авторизован).

**ПЕРВЫМ ДЕЛОМ, до любых изменений:**
1. Прочитай `HANDOFF.md` целиком — это журнал разработки (Записи 1–11), там что
   уже сделано, критичные детали и известные ограничения. Последняя запись — самая
   свежая.
2. Прочитай `README.md` (стек, архитектура, статус фаз).
3. Просмотри `src-tauri/src/` и `src/`, чтобы освежить код.

**Текущее состояние: MVP функционально готов.** Сделано:
- Все 5 фаз плана: каркас/чат/Keychain/переключатель моделей; канон в SQLite;
  GigaChat (OAuth 9443, **Russian CA встроен**, mutex); агентские инструменты
  (read/write/edit/list/grep/bash + подтверждения; native tool-use и ReAct);
  экономия токенов (rolling-summary, prompt caching, обрезка вывода, retrieval).
- Поддержка прикрепления файлов, изображений (Drag&Drop) и мультимодальность для GigaChat и OpenAI-совместимых.
- Адаптивный роутер модели, межмодельный handoff, i18n RU/EN/ES, встроенный гайд.
- Ребрендинг: фиолетовая тема, знак `LogoMark`, космический сплэш, иконка приложения.

**Стек фиксирован — без явного согласия пользователя не менять:** Tauri v2 (Rust) +
React + TS + Tailwind v4; секреты только в macOS Keychain; SQLite для канона.

**Жёсткие правила:**
- Секреты (API-ключи, GigaChat-креды) НЕ писать в файлы и НЕ коммитить — только Keychain.
- **НЕ строить** скрытую автоматизацию подписочных ИИ через фоновый браузер (обход
  ToS/детекта) — пользователь просил, отказано, см. HANDOFF Запись 2.
- Приложение локальное, наружу — только к настроенным API. Ничего «домой».
- НЕ прятать главное окно на старте (`visible:false` + JS `show()`) — в релизе окно
  остаётся скрытым и «приложение не открывается». Тёмный фон в `index.html` уже
  убирает белый мельк (см. HANDOFF Запись 12).
- Работай автономно, мелкие решения принимай сам качественно; спрашивай только
  когда это влияет на архитектуру или требует секретов.

**Проверки перед коммитом:** `cargo check` (в `src-tauri`), `npx tsc --noEmit`,
`npm run build`. Запуск dev: `npm run tauri dev` (если cargo не в PATH —
`source $HOME/.cargo/env`). Релиз-сборка (.app/.dmg): `npm run tauri build` →
`src-tauri/target/release/bundle/`.

**Когда закончишь сессию или тебя остановят — ОБЯЗАТЕЛЬНО допиши новую запись в
конец `HANDOFF.md`** (что сделал / что не доделал / следующий шаг). Старые записи
не удаляй.

**Остаток идей (опционально, не срочно):** ReAct-функции native для GigaChat,
мгновенный kill run_bash по «Стоп», регенерация ответа, экспорт чата, счётчик
токенов/стоимости, точный геометрический шрифт заголовков.

Начни с чтения HANDOFF.md и скажи, с чего продолжаешь.
